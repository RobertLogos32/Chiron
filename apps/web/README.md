# Chiron · frontend

Frontend unificato React + TypeScript con libreria per materia, PDF.js e quaderni Konva.

Da questa cartella: `npm install`, poi `npm run dev` (http://127.0.0.1:5174/).

Per struttura, utilizzo e limiti del salvataggio locale, consulta il [README del progetto](../../README.md).

`npm test`, `npm run format:check` e `npm run build` verificano tutta l’applicazione.
